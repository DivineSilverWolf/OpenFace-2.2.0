# Эксперимент: детекция длительного открытия / закрытия глаз

Описание workflow в `Experiment/`: видео, где участник **длительно** держит глаза закрытыми и открытыми (~2 минуты на фазу), и инструмент, который по CSV OpenFace предсказывает таймкоды переходов.

## Протокол эксперимента

- Запись начинается с **открытых** глаз.
- Шесть размеченных переходов за сессию (ручные файлы `Experiment/*.txt`):
  - **S1** — глаза закрыты (начало длительного закрытия)
  - **S2** — глаза открыты (начало длительного открытия)
- Длительность фазы ~**119–121 с**. Краткие моргания (1–2 с) **не** размечаются.

Пример ручного файла:

```text
# S1 - закрыл глаза
# S2 - открыл глаза
00:26 - S1
02:25 - S2
...
```

## Входные данные OpenFace

Запуск `FeatureExtraction` для каждого `.mp4` (Docker / `tools/experiment/run_experiment_extraction.sh`).  
Результаты — в `Experiment/<имя_ролика>/`.

Рекомендуемый lean-режим (только landmarks + AU):

```bash
FeatureExtraction -f <video.mp4> -out_dir <out_dir> -quiet -2Dfp -aus
```

## Колонки CSV, используемые детектором

Читается CSV последовательности от `FeatureExtraction`:

| Колонка(и) | Смысл |
|------------|--------|
| `timestamp` | Время в секундах (таймлайн видео) |
| `success` | `1` — лицо отслеживается; остальные строки пропускаются |
| `x_37`, `y_37`, `x_41`, `y_41` | Углы левого глаза (модель 68 точек) |
| `x_43`, `y_43`, `x_47`, `y_47` | Углы правого глаза |
| `AU45_r` | Интенсивность AU45 (моргание); пики — момент закрытия |

**Производные сигналы**

1. **Раскрытие век** — среднее вертикальных расстояний (37–41) и (43–47) в пикселях; больше → глаза открытее.
2. **AU45** — поиск момента закрытия (S1), в том числе первого перехода.

Для детекции не нужны gaze, HOG и полная сетка landmarks.

## Алгоритм (`detect_eye_transitions.py`)

1. **Агрегация** — медиана по **1 с** (шум и одиночные моргания сглаживаются).
2. **Первый S1** — самый ранний локальный максимум `AU45_r` > 0.85 в первых ~50 с.
3. **Сетка протокола** — ожидаемые моменты: первый S1, затем +119.5 с (S2), +239 с (следующий S1) и т.д. (всего 6 событий).
4. **Уточнение** в окне **±6 с** вокруг сетки:
   - **S1:** максимизировать `AU45_r` с штрафом за удаление от сетки.
   - **S2:** максимизировать раскрытие век с тем же штрафом.
5. Запись `*_detected.txt` в формате ручной разметки.

Краткие закрытия в окне не «перебивают» привязку к сетке, если рядом с ожидаемым длительным переходом есть более подходящий пик AU45.

## Запуск

```bash
# Все ролики + отчёт (допуск |Δt| по умолчанию 5 с)
./tools/experiment/run_detect_all.sh

# Свой допуск только для отчёта
TOLERANCE_SEC=3 ./tools/experiment/run_detect_all.sh

# Один CSV
python3 tools/experiment/detect_eye_transitions.py \
  Experiment/Co_Sin_001_own_face/Co_Sin_001_own_face.csv

# Сравнение с ручной разметкой
python3 tools/experiment/compare_eye_transitions.py \
  --tolerance-sec 5 \
  --report Experiment/REPORT.md
```

## Оценка качества

`compare_eye_transitions.py` сопоставляет события по порядку и метке (S1/S2).  
**Успех:** `|Δt| ≤ tolerance` (по умолчанию **5 с**). Параметр: `--tolerance-sec` / `--dt-tol`.

Актуальные цифры — в `Experiment/REPORT.md`.
