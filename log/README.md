# Локальные логи (не в git)

Сюда удобно складывать вывод проверок для диплома или отчёта: PowerShell parse/integration по скачиванию ассетов, скриншоты команд и т.п.

- Содержимое каталога **`log/*`** игнорируется git (кроме этого `README.md`).
- Имена файлов на ваше усмотрение; в **[WINDOWS_VERIFICATION.md](../docs/WINDOWS_VERIFICATION.md)** есть примеры команд с `Tee-Object` в `log/…`.
